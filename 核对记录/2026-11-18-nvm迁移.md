# nvm 从 Scoop 迁移到官方安装

日期：2026-11-18（Asia/Shanghai）。

## 安装与迁移

- 卸载 Scoop 的 nvm 2.0.1，未使用 purge；安装前备份原 Node 版本目录及用户 PATH。
- 使用 `winget install --id AuthorSoftware.NVMWindows --exact --source winget --silent` 安装官方 Community 版 2.0.1；winget 已验证安装包 SHA-256。
- nvm 安装目录：`C:\Users\morty\AppData\Local\Author Software\nvm`。
- 原 Node v24.21.0 能执行代码，但 npm 和全局工具存在 `NVM4306 / delegated script trust signature invalid`。官方 nvm 接管后仍无法使用，`nvm reshim` 未解决，因此按要求用新 nvm 卸载并重装同版本 Node。
- 新 Node 根目录设为 `C:\Users\morty\AppData\Local\Author Software\nvm\nodejs`，默认版本 v24.21.0；从官方 Node 源下载。
- 用户 PATH 中旧 `scoop\persist\nvm\.nodejs` 替换为官方 nvm 的 `.nodejs`，保留其他 PATH 项。
- 重装后签名问题仍存在；官方信任命令和 doctor 未解决。备份 `.verify` 公钥缓存后移出原目录，再执行 `nvm reshim` 重建，npm 恢复正常。未关闭全局信任校验，未删除 Windows 私钥。
- 恢复全局包时 Corepack 与 pnpm/Yarn 的入口冲突，改为先装 Corepack，再定向覆盖 pnpm/Yarn 入口，最后安装其余工具。
